**Official active phase remains Phase 2.**
This file captures parallel evidence that will enter Phase 3 after the Fomo gate passes. It must not be used to skip Phase 2.

## Stake Originals — high-frequency game ergonomics

Official Stake material documents recurring primitives across Originals:
- Instant Bet removes/skips animation for rapid results;
- desktop hotkeys support rapid repeated actions;
- Plinko allows spacebar-driven consecutive drops;
- Auto Mode/autobet removes repetitive manual submission;
- provably-fair verification remains available alongside simplified play;
- newer games such as Darts explicitly support multiple fast bets and state that the next wager need not always wait on visual completion.

### GAS candidates
- cinematic vs Instant Mode;
- spacebar IGNITION on desktop;
- persistent safe wager/mode controls;
- next eligible IGNITION immediately available after canonical state permits;
- fairness disclosure one level deep;
- session/budget controls evaluated as user-control UX, not buried compliance UI.

- https://stake.com/casino/games/plinko
- https://stake.com/blog/how-to-play-limbo-on-stake
- https://stake.com/blog/how-to-play-darts-on-stake

## Kalshi — portfolio semantics and quick execution

Official Kalshi help material documents:
- cash balance is distinct from fluctuating marked portfolio value;
- current position value depends on market prices/liquidity;
- actual cash-out may differ from displayed marked value;
- Quick Order Sale presents available contracts, average price and estimated payout before submit.

### GAS / future Bracket candidates
- never flatten cash, marked position value, potential payout and settled value into one misleading number;
- simple quick-order path above advanced order controls;
- execution estimate before confirmation;
- liquidity/execution reality communicated without forcing order-book knowledge.

Sources:
- https://help.kalshi.com/en/articles/13823844-portfolio
- https://help.kalshi.com/en/articles/13823814-quick-order-sale

## Robinhood Social — verified financial identity

Robinhood's March/April 2026 material describes Social beta as a community inside the financial app with live verified trades and authentic profiles.

### GAS candidates
- canonical on-protocol event IDs as social proof;
- verified activity visually distinct from user-authored claims;
- identity + financial context inside the core application rather than a detached forum.
